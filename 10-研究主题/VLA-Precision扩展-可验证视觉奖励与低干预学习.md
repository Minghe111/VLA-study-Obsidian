# VLA-Precision扩展：可验证视觉奖励与低干预学习

## 本次问题

在VLA-Precision的ACoB基础上，如何围绕可靠的视觉稠密奖励、减少人工动作纠正，形成有价值且可被实验否定的研究问题？

> [!abstract] 推荐候选
> **面向动作专家价值更新的视觉奖励主动校准：在视觉证据、短暂自主验证、人工结果标注和人工动作纠正之间分配有限反馈预算。**
> 核心假设是：部分人工接管源于奖励/成功判断不可信，而不全是缺少正确动作。若优先修正会误导策略更新的奖励证据，可能用较低成本反馈替代部分动作纠正。此假设尚未成立，不能宣称首创或已减少人工成本。

> [!warning] 2026-10-15近邻核查：收窄本候选的新颖性预期
> [IDRL，NeurIPS 2021](https://papers.nips.cc/paper/2021/hash/1fa6269f58898f0e809575c9a48747ef-Abstract.html)已经按候选策略回报差的信息增益选奖励查询；[Adaptive querying](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2025.1734564/full)已联合选择查询状态、反馈类型和成本。[SiLRI](https://arxiv.org/html/2512.24288v1)已有误奖纠正后重训分类器，[HiRE](https://arxiv.org/html/2609.27068v1)已有成功/失败轨迹驱动的奖励校准，[Verify, Act, Distill](https://arxiv.org/html/2610.14885v1)已有验证收益蒸馏。因此，不能仅凭“按更新影响选query＋多类反馈＋回灌策略”的宽组合宣称新的算法原理；针对VLA或实验室场景形成有效的适配方法、系统设计或实证结论仍可构成贡献，需按具体差异评价。仅条件保留“终局标签本身不可靠时，独立审计、测量与修复的区分，以及误奖在多轮学习中传播”的待证伪问题；完整近邻与否决实验见 [[VLA-Precision后续自进化选题-近邻排重与先导验证#5. 条件保留B：终局结果也会判错时，防止自进化放大误奖]]。下文2026-10-14设计保留为历史候选，不表示已成立新算法。

本候选延续 [[VLA动作专家适应-条件利用、多解生成与闭环强化学习]] 的实际交互RL路线；不是继续通过预测世界模型端到端反传。ACoB方法依据见 [[VLA-Precision精读-价值校准、动作专家更新与Q-VGM比较]]，本机与RealMan接入边界见 [[π0.5-RealMan强化学习研究路线-算法与训练闭环]]。

## 已有工作覆盖了哪些部分

| 工作与核查范围 | 已有机制 | 对创新判断的限制 |
| --- | --- | --- |
| VLA-Precision v3 §III-B | 实际执行转移TD；人工纠正相对原提议的排序；相对优势、FM-BC和参考约束更新动作专家LoRA | 不能把“交互奖励更新flow”或“价值校准”泛称为新方法 |
| Rewarding DINO v1 | 冻结视觉/语言表征，学习任务条件稠密评分；作者指出单帧隐藏状态混淆及成功检测限制 | 换DINO或加入小奖励头不是贡献；其PPO实验保留解析成功基础奖励和状态观察，不证明纯视觉闭环已解决 |
| Robometer v1 §III、§E | 视频语言进度、成功预测、轨迹偏好，使用失败/次优轨迹并支持自动RL | “时序信息＋失败样本＋成功头＋自动奖励”已有明确覆盖 |
| ThriftyDAgger，CoRL 2021 / PMLR 2022 | 在人工干预预算下，用新颖度和任务风险决定何时接管 | “不确定时才找人”不是独立创新 |
| IVFP官方项目页 | 交互试探视频验证抓取，自动赋予奖励并持续改善抓取；作者报告减少人工干预 | “短暂自检＋自动奖励＋少人工”也是直接近邻，必须对照 |
| Active Reward Learning，RSS 2014 | 概率奖励模型与主动专家查询，联合改进奖励和策略 | 主动学习奖励以及预算/不确定度权衡并非空白 |

以上是论文/官方页面报告与本轮方法核查，不是本机复现。检索未覆盖全部相关文献，尤其不能据此证明“价值更新影响驱动的反馈选择”首创。Rewarding DINO关于PBRS与部分观察的理论表述不在本轮独立证明范围内；本候选不承诺PBRS或置信度门控的全局策略不变性。

## 为什么从抓瓶子开始

研究对象应是**视觉相似、任务后果不同**的状态，而非只考察背景/光照扰动。例如：瓶子仍由桌面支撑与已经稳定抓起；短暂抬起与即将滑落；抓住相邻瓶与抓住指令目标。

这些是拟构建的诊断场景，不是已在用户数据中确认存在的错误。若错误正奖励被TD传播，critic可能把失败动作估得过高，继而影响相对优势和动作专家更新。单帧分数高、ensemble一致，也不代表证据充分；共同偏差可以造成高置信错误。

对“桌面支撑还是稳定抓持”，任务允许时的小幅抬起/保持可获得新的可见后果。但这一动作既改变物理状态，也带来额外耗时和风险，不能视为免费观察或假定保持状态不变。这里仅提出仿真验证方案，未授权或执行真机试探。

## 候选机制及可实现的初版

### 1. 奖励既输出任务进展，也记录证据和未知状态

冻结DINO等视觉编码器，训练任务条件的短历史奖励头；使用目标物体局部特征及相对运动信息，可加入已有本体状态，但需与对照保持相同信息来源。为接近、抓持、稳定抬起、放置等事件建立可回退的进度表示，而非假定所有帧按时间单调接近成功。不同任务事件定义需重新核查。

训练数据包含成功、实际失败及视觉近似的困难负例；不能仅将50条成功示范的时间索引当作普适进展真值。输出可包括进度、成功概率、奖励分歧与证据状态。不确定是未知标签，不自动等同于失败/零奖励。

这些表示是基础组件，单独不构成创新。关键要验证视觉误奖是否造成错误的价值/策略更新，以及反馈是否针对这一错误而有效。

### 2. 选择反馈依据其对策略学习的影响和成本

普通熵/分歧门控会优先询问“模型最不确定”的样本；候选应进一步关注“如果奖励判断错了，是否会显著改变动作专家的改进方向”。例如，候选动作与冻结参考的相对优势很接近，且这个样本在RL更新中权重较大时，错误进展比无关背景处的不确定性更值得核验。

初版可在固定离线回放上比较：奖励模型分歧、相对优势对不同合理奖励标签的敏感性、实际更新权重，并以单位反馈成本的预期错误更新减少量进行排序。需要指定敏感性的可计算近似、按整回合留出校准并比较随机采样和单纯不确定度采样。**这仍是待实现的获取函数设计，不是已经推导出的正确性保证，也不能用额外critic ensemble冒充创新；ACoB本身已使用critic ensemble。**

同时保留接触事件的预定验证规则，检验其能否发现ensemble共同偏差。奖励可信度与机器人执行风险分开估计：低奖励置信不必接管，而高执行风险也不能因奖励模型自信就继续。

### 3. 将反馈分为不同成本、不同用途

| 当前缺少什么 | 优先反馈 | 可产生的数据 |
| --- | --- | --- |
| 已有充分进展/失败证据 | 继续自主执行 | 实际转移及可信任务奖励 |
| 任务允许的短动作可揭示隐藏结果 | 自主验证 | 真实新转移、事件证据；不能伪装为原状态静态标签 |
| 画面仍难判，动作执行风险可接受 | 人工标注成功/失败或实际片段偏好 | 奖励/成功检测校准标签；通常没有正确动作 |
| 动作缺乏可行恢复或执行风险过高 | 人工动作接管 | 实际纠正动作、有效纠正排序和FM-BC样本 |

**减少结果标注不等于减少动作纠正。** 人工判断“失败了”不能代替“怎样正确恢复”的轨迹。候选能否降低接管时间，取决于SFT策略是否已有可被可信奖励发掘的恢复能力；若没有，仍需纠正示范或其他探索机制。

### 4. 通过可信数据接入ACoB，保留来源边界

可信稠密奖励进入实际执行转移的chunk回报与TD目标；待核验奖励与样本先保留来源/状态，核验后再补标或重标。初版可暂缓相关TD更新，但必须报告样本选择偏差、更新延迟和效率损失；不能把所有未知都直接填零。

人工实际纠正仍提供ACoB原有排序与FM-BC数据。只有奖励标签的样本用于奖励/TD校准，不能虚构人工正确动作。未执行的原提议没有观测后继，不能共享纠正动作产生的下一状态，也不能凭一次实际结果捏造“两个动作哪个更好”的反事实排序。若仿真要比较两候选，需同初始状态分别执行并记录两条分支，额外开销计入对照。

自检动作须作为真实动作记录；若由外部验证控制器执行，不能无记录地混入VLA原动作。按实际执行前缀K和验证时长对齐观察、回报与折扣；不能用仅执行K步得到的后果监督未执行的H步。奖励模型在线改变时记录版本，控制回放重标和critic目标漂移，相关对照保持相同更新频率。

## 怎样证明有价值

核心指标是**达到相同独立评定的任务成功率时，所需人工动作接管总时长是否更低**，并同时报告总人工成本、机器人交互/复位成本及误奖。

先在同一SFT初始化上构建视觉混淆片段，按回合/布局划分训练与留出集。比较单帧评分、时序评分、加入自主验证的评分，检查假成功、漏失败和置信度校准。仿真内部物体/接触状态可用于独立评测和指定训练标签；部署奖励模型输入不使用该特权状态，并披露监督来源和标注预算。此阶段不需要先改动大VLA或跑完整RL。

若误奖问题成立，再进行一个抓瓶任务的ACoB候选验证。拟比较：

1. 原ACoB，在相同人工预算下训练。
2. ACoB＋直接视觉/时序稠密奖励。
3. 同一奖励＋按不确定度/风险触发人工反馈；作为Thrifty式原则的适配对照，不能声称等价复现其全部算法。
4. 同一奖励＋固定事件验证/始终验证；作为IVFP思想的适配对照，额外动作计入预算。
5. 候选：按价值更新影响和反馈成本选择验证、结果标注、动作接管。
6. 仿真真实状态奖励参考，披露其信息优势，不作为可部署纯视觉方法。

统一actor可见信息、实际执行K、控制周期、初始数据、训练/奖励模型标注预算、环境步和评估任务。预算难以完全等同时，画成功率—人工分钟—机器人耗时的折中曲线，避免用单个更有利设置比较。

| 指标 | 所检验的问题 |
| --- | --- |
| 独立真实成功率、失败率 | 是否实际完成任务，而非骗过自家奖励模型 |
| 接管次数及总秒数 | 是否减少高成本人工动作纠正 |
| 结果标注次数、耗时及总人工分钟 | 是否把接管成本转移成大量标注/监看成本 |
| 自检次数、总耗时、复位和环境步 | 是否仅通过更多机器人试探换得提升 |
| 假成功/错误进展率、校准和覆盖率 | 高可信奖励是否真的可信，是否仅靠拒绝大量样本 |
| 策略学习前后表现、失败恢复率 | 是否跨回合改善，而非仅部署时反复检查 |

最终评测固定模型、关闭人工纠正；若部署保留自动验证，所有组使用统一协议并单独报告其贡献。另做移除验证服务的评测，区分VLA权重学习与外部运行时服务的收益，不能把两者混成动作专家提升。

## 否决条件与适用边界

- 若时序奖励头本身即可解决误奖，没有证据支持更复杂的主动验证。
- 若固定事件验证在等成本下同样有效，价值驱动获取函数未显示必要性。
- 若只减少人工打分，接管时间没有下降，只能报告降低标注成本。
- 若成功率或失败率恶化，少接管不构成有效结果。
- 若改善完全来自仿真特权标签、额外数据或机器人试探量，不能宣称真机低干预学习已解决。
- 若仅保持外部重试服务、关闭它后没有持续策略改善，属于执行闭环收益，不能声称动作专家已学会自我纠正。

本轮没有重跑RoboTwin、移植ACoB、训练奖励头、评估成功率或操作RM65-B。新笔记是研究候选，不改变已确认的硕士开题名称，也不把多个已有组件拼接视作已成立的新算法。
