# 闭盖带药瓶抓持失败：独立只读因果审计

核查日期：2026-10-22。对象为 `closed_cap_pick_probes/closed_filled_pick_v2_symmetry_stability` 的真实失败证据。仅CPU离线读取及源码分析，没有运行GPU、修改组件／任务／专家、改旧结果或把该失败当成开盖成功。完整数字、输入SHA与事件见同目录 `independent_failure_audit.json`。

## 结论

证据支持“闭合手指先撞到瓶盖，瓶身对向抓持从未建立，继续闭合使盖相对角不断变化并达到释放阈值，之后盖／瓶横倒”。它不是单纯握力不足，也不是先发生径向导向失稳再被错误放脱。**但接触阶段还存在显著位姿—角速度不一致，不能将这次非预期开盖当成正确螺纹动力学或受控拧盖。**

## 事件时间

动作计时从assembly step2875开始；此前11.50000055秒为初始化／稳定检查。每物理步实际4.00000019毫秒。

- 第一次保存到的碰盖：active tick3300，13.20秒，assembly step6175；盖受6.04797N手部接触，涉及 `r_inspire_right_index_2`、`r_inspire_right_thumb_4`。上一个保存样本tick3285接触为0，因此接触开始只能界定在(3285,3300]，不能凭60ms采样伪称4ms精确首碰。
- 闭盖条件第一次失效：dense tick3422，13.688秒，step6297；θ=0.15109459rad超过0.15rad限制，盖仍未释放。径向误差仅0.236微米、轴线夹角0.001841rad，轴移−0.350毫米。首失效来自转角，不来自径向／倾斜断约束。
- 轴移也超闭盖阈值：tick3509，14.036秒，step6384；轴移−1.00655毫米。
- 实际放脱：tick4010，16.04秒，step6885；θ=15.612579rad，大于允许释放角15.607963rad，轴移12.42238毫米，大于11.5毫米。未发现靠命令角或直接写pose跳过阈值。
- 放脱后一个物理步tick4011，径向4.40655毫米、倾角0.05647rad才首次超闭盖阈值。此时导向已按规则解除，不能倒推为“未释放时导向先失稳”。

全356个保存边界中，瓶身拇指接触力最大为0，瓶身其余手指接触最大1.21864N；没有一次瓶身对向接触，没有达到离桌2厘米；teacher carry_ready_boundaries=0。碰盖力后来达到314.27N。应优先解决闭合过程中手指／盖裙的几何关系，继续加大握力会把错误接触越压越紧。12颗药片的中心始终被计数为inside，只能声明中心包含，不能据此证明所有胶囊表面均未穿出。

## 每4ms钩子与坐标

assembly trace严格step1至8200连续，等于2875初始化步＋5325动作步；355个SDK24动作各15物理步。所有observation和transition均精确符合assembly_step=2875+active_tick；反力诊断时间均为前一个物理步。静态路径中，初始化经 `_step_simulation` 成对调用before/raw-step/after；进入动作时ClockedTask24Adapter把scene.step绑定到advance，advance只调用一次保存的raw-step并成对维护机制。现有代码、配对保护与日志未显示重复或漏钩子。

独立用body/cap保存的world pose重建相对pose：径向与轴移差小于0.21微米，倾角差小于2.74e−7rad。用相对四元数重建并unwrap的角度最大差2.34e−7rad；单步最大角增量0.10569rad，明显小于π，且分解未接近swing-twist奇异点。**这些只证明角度记录与位姿相符，不能证明速度与能量正确。**

## 位姿—角速度分歧：已证实部分与未决边界

step6176至6885的接触窗口中，姿态测得相对转角净增加+15.615360rad；用body和cap各自相邻world四元数增量独立重建角速度差，再投影到body Z，积分为+15.615362rad，两者基本一致。然而日志保存的投影相对角速度积分为−9.783665rad，逐步RMS分歧约13.852rad/s。接触前同样处理的姿态投影与twist几乎一致；异常主要出现在强接触后。

源码的投影本来就是 `(omega_cap_world-omega_body_world) dot body_Z`，没有明显漏减body自转。严格swing-twist角速率还包含横向ω与相对swing项；现有日志只存轴向投影scalar，没有body/cap完整world ω向量，故无法在同瞬时重算全部项，也无法唯一判定是速度取样／坐标语义问题，还是接触求解造成未由速度正常积分解释的位置校正。相邻位姿的独立重建使简单unwrap／正负号／body随动遗漏解释更不可信，但仍不能用它代替真实速度向量日志。

后续应在同一4ms边界同步保存body/cap完整world angular velocity、pre/post pose、cmass pose和速度；以完整公式核算twist导数，再做无接触与有界盖接触对照。当前不修改冻结组件、不为了通过而加伺服或弱化闭盖判据。几何修复也需要在新目录实际复验，不能抹掉这次不一致。
