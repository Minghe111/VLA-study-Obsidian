# 瓶身反馈 v5：保留 drive 预载已证实，但仍未得到正向开盖

本次独审只读 terminal 证据；没有 GPU/新物理步或源码修改。24 份冻结源 SHA 匹配，入口 `ec3457c7…`；原物理、左手控制及 100 µrad 观察预算保持。本轮转动前 q36/qvel、drive、root、双掌、瓶/盖/12 药片等全字段与 v3 一致，738 个此前完整目标逐项相同。

第一窗零瓶身误差时，实际 right drive 精确保持不变。11070→11085 的 action/state/next_state、时钟，以及 q36/qvel、root、右掌、瓶/盖/药片实际读回均与 v3 完全相等，消除了 v4 的无误差命令跳变。随后 11 行反馈均独立重算通过：按 qIK−actual_start 修正 current_drive，零误差 delta=0；scale、预载向量与记录的右臂目标一致，叠加后的目标在严格关节界内，命令峰值速度约 0.036515 rad/s。目标限速不能当作实际关节速度保证；末态原始 qvel36 已完整保存在 JSON，包括接触下手指瞬态，不裁剪实测值。

实际共 749 个完整 60 ms 目标/11235 个 4 ms 步，状态、world pre/post、tick 链连续，partial 为空。其中第一个 0.005 rad 增量于 11175 完成，之后已进入第二个增量并执行了四个完整控制窗口。`partial=null` 只说明没有中断的 60 ms 窗口，不表示第二个较高层增量完全没有执行。

11070→11235 的 165 个实际转动步中，164 步满足双指 >0.05 N 的对向法向载荷。index 最小/平均/最大约 0.0490/0.1188/0.2418 N；thumb 为 0.2667/0.9616/1.2550 N。右手触盖载荷最小/平均/最大约 0.7369/0.9639/1.2765 N，末值 1.2682 N。逐 4 ms 核查的新增右手—桌面/药片/自身/非手部瓶身，以及原左手禁碰类别，法向载荷最大均为 0。thumb 执行通道仍固定，较高法向载荷不是独立 thumb 力反馈的结果。

在同一实际时刻 11235 比较，瓶身世界旋转向量在初始瓶轴上的投影从 v3 的 +0.00436791 rad 降为 +0.00135986 rad；但右掌反向移动的轴投影为 −0.00859452 rad，盖的世界投影从 v3 的 +0.00329590 rad 变为 −0.00100542 rad。盖相对瓶身的转角仍减小 0.00236553 rad。该有限对照显示瓶身随动受到抑制，同时盖运动和触盖载荷发生变化；不能称为稳定正向开盖，也不能将这种系统变化仅归因于某一摩擦接触点。

11235 后下一 proposal 因原始 primary thumb_2=−103.39133 µrad 超过 100 µrad 观察预算而拒绝，follower thumb_3=−534.80244 µrad；未扩阈值、未 clamp。盖未释放、完整任务仍 false，不是可用开盖倒药数据集。reported contact 只有法向，不可推断完整切向摩擦或总接触扭矩。完整 source/逐行反馈计算/等时与等增量姿态对照/原始接触摘录见同目录 JSON 和脚本。
