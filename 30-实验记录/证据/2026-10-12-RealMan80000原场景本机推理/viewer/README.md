# RM65-B 本机推理画面

本轮使用本机 80000 步检查点，从六条专家数据的原始起点独立推理。页面：`http://127.0.0.1:8768/`。

- 三路策略相机和固定外部观察相机均来自当前物理仿真的新捕获。外部相机只供观看，不进入模型。
- 页面随实际新增帧自动显示。模型思考时保留当前画面，并显示状态、帧序号、仿真时间和实际相机帧龄；完成或停止后明确标注最后一帧。
- 兼容内置浏览器：SSE 只在新帧产生时更新 JPEG 显示；标准浏览器另可使用 `/mjpeg/head`、`/mjpeg/left_wrist`、`/mjpeg/right_wrist`、`/mjpeg/external`。
- 首轮六场完成并核查后，“重新运行一个原场景”开放。只能选择同样六个原场景。每次复测单独保存到本轮 `episodes/manual_*`，不覆盖首轮结果，也不计入首轮六场统计。
- “停止本次复测”只结束由页面启动的当前仿真进程。80000 步模型仍在本机显卡上，可以继续启动下一场。
- 关闭页面不会卸载模型。需要释放显存时，在实验线程要求关闭本机模型服务。模型服务仅监听 `127.0.0.1:8769`；画面服务仅监听 `127.0.0.1:8768`。

程序与本轮录像位于 `/tmp/realman-eval80k-20261012/`。实验笔记库保存正式结果与视频；临时运行目录可能在重启后清理。恢复服务需要原训练检查点、原始起点资料和对应脚本。

## 实现入口

`publish_live.py` 提供 `LivePublisher`。仅在真实相机捕获后调用 `update(images=..., metadata=...)`；metadata-only 更新不重复发布旧图。每条场景新进程会继承全局帧序号。

`server.py` 提供本机页面、真实帧、MJPEG、状态 SSE，以及本轮 MP4 回看。`manual_runs.py` 只调用固定的 `scripts/run_model.py`，参数只允许六个 index，固定模型身份与本机推理服务，并使用独占锁禁止并发。开启复测还要求首轮六份完整报告、服务就绪且身份一致、没有正在运行的本轮仿真。

`retest_config.json` 默认关闭复测；核查首轮后才设置 `enabled=true`、`batch_complete=true`。请求 token 每次画面服务启动时生成，只在进程内使用，不写入笔记或 Git。

`test_stream.py`、`test_manual.py` 使用独立临时目录、测试图像或假进程验证组件；不向本机推理画面发布测试内容，不加载模型或发送推理请求。`verify_live_stream.py` 则核查真正执行期间的新增相机帧、物理时间及模型查询次数。
