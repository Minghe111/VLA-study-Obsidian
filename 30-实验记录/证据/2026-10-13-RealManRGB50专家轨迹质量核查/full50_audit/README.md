# 新50条专家轨迹运动审计

只读分析源 HDF 的原数值数组，没有重跑仿真、模型或实机。50条 NPZ、每字段字节 SHA256 均再次与下载回执匹配；源数值文件未改动。覆盖166470个4ms物理步和11098个60ms观测。

主要产物：

- `summary.json`：定义、全50计数、排名和时钟/字段一致性核查。
- `all50_motion_audit.json`：每条、每臂、每关节、整条和首次明显闭合之前的完整指标。
- `joint_metrics.csv`：4800行，分真实物理测量、低频真实测量、4ms命令、60ms下一目标。单关节分别统计，不将六关节路程相加。
- `arm_path_orientation_metrics.csv`：200行，整条和闭合之前的末端位置路径、相机世界位置路径和SO(3)姿态路径。
- `seven_actual_q6_ge360.json/.csv`：7条真实J6连续坐标范围≥360°的详细角度、极值时刻、首个净位移达到360°区间、回摆量、命令及4ms步差。

角度主结论使用 `realman_dexterous_physics/measured_state24_before/after`。其与full36物理Qpos指定列、低频特殊measured_state24完全相符。full36左右臂是交错列：左1,3,5,7,9,11；右0,2,4,6,8,10（均0起始）。普通 `state/*_arm_joint_states` 别名与特殊真实测量并不完全相同，最大相差约0.45°；本报告不把该别名当作真实角度主依据。

7条实际J6范围≥360°：1、17、18、47、34、29、20。其中17、18、34、29、20在首次明显SDK闭合之前就达到该范围；1、47的整段范围超过360°，首个360°净位移区间夹有约11°回摆。所有实际角度无unwrap修正、4ms最大步差远小于1°，命令中也没有近±2π突跳。

“闭合之前”仅按任何前五个弯曲SDK通道的实际应用命令首次低于950定义，相对名义全开1000下降50；排除第六个拇指旋转通道。它是诊断切分，不能代表首次物理接触、首次抓住或仍无碰撞。位姿路径在实际60ms观测处截取，不插值。

`state/*_ee_poses` 的位置属于RoboTwin采集适配器的corrected legacy world EE框架，包含其固定本地+0.06m约定，不是经过实机校准的TCP；另列实际腕相机camera-to-world model matrix的中心路径作独立检查。空间累计路径/首末直线位移用于描述绕行程度，不证明空间圆圈或具体碰撞。

SO(3)累计角是相邻姿态最短角的非负和；超过360°不代表绕同一固定世界轴转了一圈。首末SO(3)夹角本来就只有0–180°，不能用它数整圈。真实J6坐标范围≥360°说明该关节相对前一连杆经历大幅角度变化，仍不等于整个手腕绕固定世界轴旋转。

`audit_all50.py` 可重复生成产物。分析单位是rad、m、s，报告另换算deg。闭合阈值、2π跳变容差0.1rad、单向段微反转容差1e-5rad均在JSON中明示。单关节范围、累计往返、端点路径和姿态累计严格分开。
