# 采集前杂物稳定准备核查-2026-10-14

## 原始拒收与初始化覆盖

现有 V2 的 `slot_0000034_randomized_attempt_002` 在第 20 个实际 4 ms 步骤、即约 80 ms 时因杂物碰撞顶点相对 t0 的位移 **1.017099772 mm** 超过 1 mm 被拒收。第 18、19 步分别为 0.917801937 mm、0.967561783 mm；三个步骤的 target/robot 与 clutter 活跃接触均为 0。该 guard 拒收符合其原定契约，不应增加漂移预算或删除杂物来绕过。

证据路径为本机历史候选目录 `/home/admin123/liminghe/vla-benchmark/deploy/realman_gen4/rgb50_motion_quality_20261013_v2_conservative/new_physical_episodes/slot34_trials/slot_0000034_randomized_attempt_002` 的 `runner_error.json`、`physics_trace.json` 与 `randomized_environment_coverage.json`。旧 trace 只保存全场最大值，没有逐个 clutter entity/link 的动态 pose，**不足以从既有记录指认具体漂移实体**；此处未把某个杂物名称推测为已验证原因。

冻结官方 `Base_Task.check_stable` 在完成生成后先执行 2000 步，再执行 500 步，仅比较各 `get_all_actors()` 返回 actor 的最终四元数与末尾 200 步四元数：超过 3° 才拒收。它不检查平移，也不按 articulation 的全部碰撞 link 计算顶点位移。稳定检查失败的 086_wood / 066_vinegar 历史情况与通过初始化后出现早期平移的情况应保留为不同失败类型。

## 独立准备 helper

新增 `pre_recording_clutter_settle.py`，不修改被冻结入口、官方初始化、原专家方法或环境 guard。接入位置为新 variant 中完整 `old_prepare` 返回后，首次 randomization / hardware / environment baseline 与专家捕获之前。

每次准备只调用真实 `task.scene.step()`，保持原生约 4 ms 时间步。默认最多额外 1000 步，约 4 秒；要求连续 250 步，约 1 秒，覆盖全部十个官方杂物的全部 native collidable component。原 guard 的实际 native mesh scale、shape local pose 与 entity pose 提取被复用；多 link articulation 按 link collision component 覆盖。

对每个组件、每相邻 4 ms 样本，计算所有实际碰撞顶点的最大世界位移。在完整窗口内累加该最大值；三角不等式保证窗口中任意两帧任意同一顶点的位移不大于该总变差上界。窗口内每个组件的上界必须 ≤0.1 mm。该判据比只比较首尾更保守，避免往返运动相消。未稳定、覆盖不足、时钟错误、接触、source/geometry 身份变化、瓶子姿态类别或近臂检查不通过均拒收；官方 clean draw 与不足十件的 placement 也会拒收，而不重新采样或改 RNG。

helper 不调用 native wake、不写 pose / 速度 / 驱动 / 几何 / 摩擦 / 质量 / SDK、不调用渲染或额外 RNG，也不连接真实机器人。原 `_rgb50_initial_extra_settle_receipt` 连同 wake 历史保持原样；另保存准备后的实际状态，不把旧 wake 最终读取伪装成新的 t0 状态。

每一实际准备步骤写入 `pre_recording_clutter_settle_steps.jsonl`，包括各 entity/component 身份、名称、shape 数、原生几何摘要、动态 pose、逐步/相对准备开始的最大顶点位移、稳定窗口证明上界和接触。准备前的 scene sample、碰撞组件和瓶子真实姿态保存于 `pre_recording_clutter_settle_initial.json`。成功后 scene sample 的 `initial_pose`、瓶子中心、轴向、近臂距离和全机器人 qpos 是准备后的真实读取，旧 scene 保留在 `pre_clutter_settle_scene_sample`。

准备完成后，SDK24 的 15×4 ms / 60 ms 录制从新的真实 t0 开始。准备步骤属于采集前物理，不能加入或冒充专家步骤；原执行 guard 仍从准备后快照监控每个实际步骤的 1 mm 漂移预算和无接触要求。
